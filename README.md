# SAGA website demo

This is the Vercel-ready Next.js version of the SAGA premium motion concept.

## Deploy to Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Vercel will detect Next.js automatically.
4. Keep the defaults and click **Deploy**.

No environment variables are required for this demo.

## Local run

```bash
npm install
npm run dev
```

The main page is in `app/page.tsx`; the design and animations are in `app/globals.css`.
